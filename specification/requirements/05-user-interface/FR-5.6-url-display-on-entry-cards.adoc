[[FR-5.6]]
=== FR-5.6 URL display on entry cards

The system shall display URLs attached to an entry via a compact drop-down list behind a dedicated icon in the top-right area of the entry text block, so that the text display is not cluttered by visible URLs.

.Acceptance criteria
. If an entry has attached URLs, a dedicated link/icon button is shown in the top-right area of the entry text block
. If an entry has no attached URLs, the link/icon button is not shown
. Activating the icon by mouse click, keyboard, or touch opens a drop-down list of the attached URLs
. The drop-down list shows all URLs attached to the entry
. Each URL in the list shows its corresponding `favicon.ico` where available
. If no favicon can be resolved for a URL, a default favicon is shown instead
. The URL list presentation avoids cluttering the visible quote/citation text area
. Selecting a URL in the list opens the selected URL in the browser
