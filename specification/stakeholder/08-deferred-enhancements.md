# §8 Deferred enhancements

Wishes that are out of scope for now, with the reason.

1. **FE-1 Natural language folders**: describe a folder in plain words ("quotes about love from
   2024 near Paris") and let an LLM turn it into folder criteria. Deferred: needs an external
   API and a network.
2. **FE-2 Label suggestions**: an LLM suggests labels from the entry text. Deferred: needs an
   external API.
3. **FE-3 Label management**: view, rename, delete and merge labels. Deferred: managing labels
   through use is enough so far.
4. **FE-4 Cloud sync**: synchronize the collection across devices through the user's own cloud
   storage. Deferred: local-only approach.
5. **FE-5 Sharing**: share quotes, public and private collections. Deferred: needs a server.
6. **FE-6 Localization**: translated interface, locale-aware dates and numbers, right-to-left
   layouts. Deferred; the architecture should not prevent it.
