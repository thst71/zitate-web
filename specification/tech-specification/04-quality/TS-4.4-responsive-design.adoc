=== TS-4.4 Responsive design

Implements <<FR-5.1>> and <<NFR-3>>.

==== Breakpoints
- Small phones: up to 480px
- Phones and small tablets: up to 768px
- Desktop: above 1024px
- The styles are written for the desktop and adapted with `max-width` media queries; a few components add `min-width` queries

==== Layout Strategy
- CSS Grid for main layouts
- Flexbox for component layouts
- Touch targets min 44px on mobile
- Each component has its own stylesheet next to it (`EntryCard.css` beside `EntryCard.tsx`)

==== CSS Architecture
Design tokens are CSS custom properties in `src/styles/variables.css` (colors, spacing, typography, radii), with dark values under `prefers-color-scheme: dark`. Excerpt:

[source,css]
----
/* CSS Custom Properties for theming */
:root {
  --color-primary: #3b82f6;
  --color-bg: #ffffff;
  --color-text: #1f2937;
  --spacing-unit: 8px;
  --border-radius: 8px;
}

@media (prefers-color-scheme: dark) {
  :root {
    --color-bg: #1f2937;
    --color-text: #f9fafb;
  }
}
----
