=== TS-4.3 Offline capability

Implements <<NFR-6>>.

==== Service Worker Strategy
`vite-plugin-pwa` generates the service worker with Workbox at build time (`vite.config.ts`):

- `registerType: 'autoUpdate'`: a new version is installed and activated when the app is online
- Precache: all built assets matching `**/*.{js,css,html,ico,png,svg,woff2}`
- Runtime cache `openstreetmap-tiles`: tiles from `tile.openstreetmap.org`, `CacheFirst`, at most 500 tiles for 30 days
- Nominatim requests are not cached; offline, the UI shows coordinates instead of addresses

==== UI
- `OfflineIndicator` shows when the browser is offline (`navigator.onLine`, `online`/`offline` events)
- `InstallPrompt` offers the installation when the browser fires `beforeinstallprompt`
