[[TS-2.6]]
=== TS-2.6 Object store audio

Implements <<FR-1.4>>.

[source,typescript]
----
interface AudioAttachment {
  id: string;                    // UUID v4
  entryId: string;               // FK to entries
  blob: Blob;                    // Audio data
  mimeType: string;              // audio/webm, audio/ogg, etc.
  duration: number;              // Seconds (max 300)
  createdAt: number;             // Unix timestamp (ms)
}

// Key: id. Indexes: entryId
----

The store, the model and the export/import of audio exist; recording and playback (<<US-4.3>>) are not implemented yet.
