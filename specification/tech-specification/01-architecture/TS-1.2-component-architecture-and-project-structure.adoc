=== TS-1.2 Component architecture and project structure

Implements <<NFR-2>>.

==== Component-Based Architecture
- *Components:* Reusable React UI components
- *Hooks:* Custom React hooks for shared logic and state management
- *Services:* Singleton business logic services (db.service, location.service)
- *Models:* TypeScript interfaces for type safety

==== State Management
- *Local State:* Component state (useState)
- *Persistent State:* IndexedDB via custom hooks (useEntries, useAuthors, useLabels, useFolders)
- *Cross-instance sync:* Custom event emitter (storeSync) to keep multiple hook instances in sync
- *Derived State:* Computed values from IndexedDB queries (useCallback, useMemo)

==== Data Flow

[source]
----
User Interaction → Component → Hook → Service → IndexedDB
                    ↑                              ↓
                    └────── State Update ←─────────┘
----
