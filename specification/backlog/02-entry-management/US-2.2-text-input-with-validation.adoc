=== US-2.2 Text Input with Validation

Effort:: 3 h +
Traces to:: <<TS-2.2>>, <<TS-4.2>>, <<FR-1.1>>

As a user, I want to enter text for my quote, so that I can record the saying or citation.

.Acceptance criteria
. Multi-line textarea
. Character counter showing 0/10,000
. Validation error if empty or >10,000 characters
. Real-time validation as user types
. Visual feedback (color coding)

.Technical tasks
. Add textarea to EntryForm
. Add character counter display
. Implement onChange handler with validation
. Add visual feedback (border color, error message)
. Disable save button if invalid
. Add debouncing for real-time validation
. Test with various inputs (0 chars, 10000 chars, 10001 chars)

.Test criteria
* Not recorded before the migration; the tests named in the technical tasks apply.
