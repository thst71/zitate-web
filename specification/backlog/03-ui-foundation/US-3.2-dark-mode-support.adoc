=== US-3.2 Dark Mode Support

Effort:: 4 h +
Traces to:: <<TS-4.4>>, <<FR-5.1>>

As a user, I want to use dark mode, so that the app is comfortable at night.

.Acceptance criteria
. Detects system preference (prefers-color-scheme)
. CSS custom properties for colors
. All components styled for both modes
. Optional: Manual toggle (future)

.Technical tasks
. Define CSS custom properties in styles/variables.css
. Create light theme values
. Create dark theme values with @media (prefers-color-scheme: dark)
. Update all components to use custom properties
. Test in both modes
. Ensure WCAG contrast ratios met

.Test criteria
* Not recorded before the migration; the tests named in the technical tasks apply.
