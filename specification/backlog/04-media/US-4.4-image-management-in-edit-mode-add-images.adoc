=== US-4.4 Image Management in Edit Mode – Add Images

Effort:: 4 h +
Traces to:: <<TS-3.4>>, <<FR-1.3>>

As a user, I want to add new images when editing an existing entry, so that I can attach additional visual context later.

.Acceptance criteria
. ImageUpload component is shown in edit mode (not only on creation)
. New images are compressed, stored in IndexedDB, and linked to the entry
. Entry's imageIds array is updated with the new IDs
. Max 10 images per entry limit is enforced (existing + new)
. Existing images remain visible alongside newly added ones

.Technical tasks
. Remove `!isEditing` guard on ImageUpload in EntryForm
. Create ImageEditor component combining existing images + upload
. Extend updateEntry in useEntries to accept new images (SelectedImage[])
. Save new images via saveImages, append IDs to entry.imageIds
. Pass existing image count to ImageUpload for limit enforcement
. Update App.tsx handleSaveEntry to forward selectedImages on edit

.Test criteria
* Not recorded before the migration; the tests named in the technical tasks apply.
