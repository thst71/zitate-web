== Technical Debt Tracking

=== Known Compromises for v1.0

1. **LLM Features:** Deferred to v2.0 (FE-1, FE-2 in SPEC.md §8)
2. **Cloud Sync:** Deferred to v2.0 (FE-4 in SPEC.md §8)
3. **Advanced Media Editing:** No cropping/filters in v1.0
4. **Social Features:** Deferred to v2.0 (FE-5 in SPEC.md §8)
5. **Multi-language:** Deferred to v2.0

These will be prioritized based on user feedback after v1.0 launch.
