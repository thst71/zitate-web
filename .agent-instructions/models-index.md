# Model Specific Instructions Index

For any model, read the `models/general.md` file for instructions.

If you are a Claude (e.g. Claude 3, 3.5, 3.7 Sonnet) model, additionally read the `models/claude.md` file. Ignore the other files in the `models/` folder.

If you are a Reasoning model (e.g. OpenAI o1, o3-mini, Gemini Thinking), additionally read the `models/reasoning.md` file. Ignore the other files in the `models/` folder.

If you are a GPT-4o model, additionally read the `models/gpt4o.md` file. Ignore the other files in the `models/` folder.
